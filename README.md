# Nishant Narsale — Modified Premium Portfolio

This version is a self-contained `index.html`. CSS and JavaScript are embedded in the HTML, so replacing the existing `index.html` is sufficient.

## Update the GitHub site

1. Open the existing repository.
2. Open `index.html`.
3. Click the pencil/edit icon.
4. Replace the entire file with the supplied `index.html`.
5. Commit directly to `main`.
6. Wait for GitHub Pages to redeploy.
7. Refresh https://nishantn-iitm.github.io/

## Before publishing
Replace:
- `YOUR-LINKEDIN-URL`
- workshop placeholders
- conference placeholders
- CV path if your filename differs
