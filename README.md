# Nishant Narsale Research Portfolio

Responsive static website built with HTML, CSS, and JavaScript.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Customize before publishing
Replace the placeholders for:
- LinkedIn URL
- Workshop names, organizers, dates
- Conference presentation titles, venues, dates
- Any project links or descriptions

## Deploy on GitHub Pages
1. Create a repository named `NishantN-IITM.github.io` for a personal homepage, or use any repository name.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Commit to `main`.
4. Go to **Settings → Pages**.
5. Set **Source** to **Deploy from a branch**.
6. Select **main** and **/(root)**.
7. Save.

For a personal homepage repository, the site will be available at:
`https://NishantN-IITM.github.io/`

For another repository, for example `research-portfolio`, it will be:
`https://NishantN-IITM.github.io/research-portfolio/`

## Local preview
Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
